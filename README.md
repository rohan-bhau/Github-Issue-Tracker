1-  What is the difference between var, let, and const?
    These all are the method of declaring variables in js. var is function-scoped, hoisted and re-declarable. let and const are block-scoped,, let allow reassignment of a value but const dosen't allow reassignment.



 2-  What is the spread operator (...)?
    The spread operator (...) in javascript is a syntax that expands iterables like and arrays or string or objects properties into individual elements.



  3️- What is the difference between map(), filter(), and forEach()? 
    - map creates a new array by transforming each element of the original array. It is same as the original array
    - filter creates a new array with only the elements that satisfy a specific condition.
    - forEach() is used to execute a function for each element, typically for side effects like logging or DOM manipulation.	


 4- What is an arrow function?
    arrow function is an element of ES6. It is used by using an arrow (=>) to separate parameters from the function body. It is a shorter form of a function

 5- What are template literals?
    Template literals are JavaScript string literals, introduced in ES6, that allow for embedded expressions (${expression}), multi-line strings, and string interpolation, enclosed by backticks (`) instead of quotes.
